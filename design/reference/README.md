# ADB View — Frozen Design Reference

`stitch_adb_view_frozen_design.zip` contains the complete Stitch design history, including Pass A through Pass F.

The ZIP is reference evidence, not the governing specification by itself.

Authority is defined by the root `DESIGN.md`:

- Pass B.1 — visual/component master
- Pass C.1 — semantic-state master
- Pass C.3 — composition/density/scrolling reference
- Pass D.1 — light/opaque/forced-colors direction
- Pass E.1 — motion/interaction reference, subject to corrections in DESIGN.md
- Pass F — application/tray icon master

If any prototype code or later Stitch board conflicts with `DESIGN.md`, `DESIGN.md` wins.

Do not copy a single Stitch prototype wholesale into production. Production components must reconstruct the frozen design according to the authority hierarchy above.
